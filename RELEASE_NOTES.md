# WukongBench 1.0.0

Автоматический запуск двух проходов Black Myth: Wukong Benchmark Tool на Windows:

- CPU-профиль: окно 1280×720, низкое качество, масштаб 25%, трассировка и генерация кадров отключены.
- GPU-профиль: исходное разрешение, максимальное качество, масштаб 100%, полная трассировка «Ультра», генерация кадров отключена. Для оборудования без поддержки трассировки — `--no-rt`.
- Получение среднего, минимального, максимального FPS и 5-го перцентиля с экрана результатов игры.
- Характеристики ПК через WMI, HTML/JSON-отчёт, исходные скриншоты и настройки каждого прохода.
- Резервное копирование и восстановление конфигурации; диагностика при ошибках.

Распакуйте архив целиком. Запуск из PowerShell: `.\WukongBench.exe run`.

Сборка включает .NET runtime. Требуются Windows x64, установленный Steam и Benchmark Tool, русский интерфейс бенчмарка и русский компонент Windows OCR. Во время работы не переключайте окна. Полные требования и ограничения приведены в README.md.

Проверено на i5-14600KF / RTX 5070 / 32 GiB RAM: CPU — 211 FPS, GPU — 90 FPS в среднем. Эти значения относятся к указанным профилям и компьютеру; методика и контрольный прогон описаны в VALIDATION.md.
