# Публикация и сдача

Локальный репозиторий и архив исходников подготовлены. Ссылка на GitHub появится только после публикации: приведённые ниже команды не выполнялись автоматически.

## Публикация через GitHub CLI

В корне проекта выполните вход в свой аккаунт:

```powershell
gh auth login
```

Создайте публичный репозиторий и отправьте подготовленную ветку `main`:

```powershell
gh repo create wukong-benchmark-automation --public --source . --remote origin --push --description "C# automation for Black Myth: Wukong Benchmark Tool: CPU/GPU profiles, OCR and reports"
```

Если такое имя уже занято, выберите другое. Для уже существующего пустого репозитория добавьте его реальный URL через `git remote add origin <URL>` и выполните `git push -u origin main`.

Прикрепите готовую сборку к Release:

```powershell
gh release create v1.0.0 artifacts/WukongBench-win-x64.zip --target main --title "WukongBench 1.0.0" --notes-file RELEASE_NOTES.md
```

Для варианта без GitHub загрузите `WukongBench-submission.zip` в облачное хранилище и предоставьте проверяющему доступ на чтение. Не отправляйте только ссылку на локальный файл.

Замените квадратные скобки реальными ссылками после публикации:

> Решение: [ссылка на GitHub или облачную папку].
