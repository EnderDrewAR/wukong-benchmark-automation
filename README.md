# Автоматический запуск бенчмарка Wukong

Программа на C# выполняет два теста в Black Myth: Wukong Benchmark Tool: первый с настройками для проверки процессора, второй — видеокарты. После каждого теста она считывает FPS с экрана и сохраняет отчёт.

## Как запустить

Нужны Windows 10/11 x64, Steam и установленный Black Myth: Wukong Benchmark Tool. Сначала один раз откройте бенчмарк вручную, пройдите начальные настройки и закройте его.

Проверка проводилась с русским интерфейсом игры. Для распознавания текста нужен русский компонент OCR Windows, для библиотеки Tesseract — Microsoft Visual C++ 2015–2022 Redistributable x64.

1. Скачайте [готовую программу](https://github.com/EnderDrewAR/wukong-benchmark-automation/releases/download/v1.0.0/WukongBench-win-x64.zip) и распакуйте архив целиком.
2. Откройте эту папку в терминале PowerShell.
3. Выполните команду:

```powershell
.\WukongBench.exe run
```

Дальше программа сама выполняет оба прохода. Пока она работает, не переключайте окна и не блокируйте компьютер: ей нужно нажимать кнопки в игре и делать снимки экрана.

После завершения откройте `artifacts/<дата-время>/report.html` в браузере. Там будут характеристики компьютера, настройки и FPS. Рядом сохраняются результаты в JSON, скриншоты и копии настроек. Исходные настройки игры восстанавливаются после работы программы.

Если запускаете из исходников, установите .NET 10 SDK и выполните в корне проекта:

```powershell
dotnet run --project WukongBench -c Release -- run
```

## Как это работает

1. Программа находит папку игры через данные Steam.
2. Сохраняет копию файла настроек `GameUserSettings.ini`.
3. Записывает настройки CPU-теста, запускает игру и нажимает нужные кнопки.
4. Ждёт экран результатов и распознаёт цифры FPS на скриншоте.
5. Закрывает игру и повторяет те же действия с настройками GPU-теста.
6. Сохраняет отчёт и возвращает старые настройки.

Для чтения экрана используется OCR — распознавание текста на изображении. Windows OCR читает подписи в меню, а Tesseract — цифры результатов. В исследованной установке не удалось найти текстовый экспорт результатов, поэтому выбран такой способ. Данные о процессоре, видеокарте и памяти берутся через WMI — системный интерфейс Windows.

## Почему выбраны такие настройки

| Настройка | CPU-тест | GPU-тест |
|---|---|---|
| Разрешение | 1280×720 | Исходное разрешение пользователя; при проверке 2560×1440 |
| Масштаб рендера | 25% | 100% |
| Качество графики | Низкое | Максимальное |
| Полная трассировка лучей | Выключена | Ультра |
| Генерация кадров | Выключена | Выключена |

В CPU-тесте снижены разрешение и графика, чтобы уменьшить работу видеокарты и сильнее проявить ограничение со стороны процессора. Это проверялось дополнительным запуском при 960×540: средний FPS изменился с 211 до 213. Разница около 1%, поэтому дальнейшее снижение разрешения на этом ПК почти не помогло.

В GPU-тесте высокое разрешение, максимальная графика и трассировка увеличивают нагрузку на видеокарту. Генерация кадров отключена, чтобы результат не учитывал добавленные ею кадры. VSync и ограничение FPS также отключены в конфиге.

## Полученные результаты

Проверка от 5 октября 2026 года: Intel Core i5-14600KF, NVIDIA RTX 5070, 32 GiB RAM. Версия бенчмарка — 1.0.3.14649.

| Тест | Средний FPS | Минимальный | Максимальный | 5-й перцентиль |
|---|---:|---:|---:|---:|
| CPU | 211 | 110 | 284 | 191 |
| GPU | 90 | 69 | 110 | 77 |

FPS — число кадров в секунду. 5-й перцентиль характеризует нижнюю часть распределения FPS и помогает оценить просадки. Значения двух тестов нельзя использовать как сравнение скорости CPU и GPU: настройки в них разные.

## Где что находится в коде

Начать чтение удобнее с `WukongBench/Program.cs`: там записан порядок выполнения двух тестов.

| Файл | За что отвечает |
|---|---|
| `SteamInstallation.cs` | Находит установленный бенчмарк |
| `SettingsManager.cs` | Сохраняет, меняет и восстанавливает настройки |
| `BenchmarkController.cs` | Проходит меню и ждёт результата |
| `GameWindow.cs` | Работает с окном, нажимает кнопки и делает скриншоты |
| `OcrReader.cs`, `ResultReader.cs` | Читают текст и цифры со скриншота |
| `HardwareInfo.cs` | Собирает характеристики ПК |
| `ReportWriter.cs` | Записывает HTML- и JSON-отчёты |

## Дополнительные команды

Для видеокарты без поддержки полной трассировки:

```powershell
.\WukongBench.exe run --no-rt
```

Чтобы проверить чтение сохранённого результата без запуска игры:

```powershell
.\WukongBench.exe parse examples\gpu\results.png
```

Проверка распознавания на двух сохранённых скриншотах и сборка программы из исходников:

```powershell
pwsh -NoProfile -File tests\Verify.ps1
dotnet publish WukongBench -c Release -r win-x64 --self-contained true -o artifacts\release
```

## Ограничения

Проверка выполнена на одном компьютере с русским интерфейсом игры. На другом оборудовании настройки CPU-теста может понадобиться подобрать заново. Изменения меню игры могут потребовать правок распознавания.

Фоновые приложения, снимки экрана и OCR влияют на производительность. Поэтому приведённые числа показывают результат конкретного запуска, а не лабораторного измерения.

При обычной ошибке или отмене через Ctrl+C настройки восстанавливаются. При выключении питания нужно закрыть игру и вернуть их из `original-GameUserSettings.ini` в папке результатов.

[Лицензии сторонних компонентов](THIRD-PARTY-NOTICES.md). В публичных примерах удалён идентификатор монитора; скриншоты и результаты не изменены.
