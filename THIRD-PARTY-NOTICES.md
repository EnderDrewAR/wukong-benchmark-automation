# Зависимости

- Tesseract .NET wrapper 5.2.0: https://github.com/charlesw/tesseract — Apache-2.0.
- Tesseract OCR и Leptonica входят в нативные библиотеки NuGet-пакета Tesseract; их лицензии доступны в исходном проекте пакета.
- Английская модель `eng.traineddata`: https://github.com/tesseract-ocr/tessdata_fast — Apache-2.0. Копия лицензии лежит в `WukongBench/tessdata/LICENSE`.
- Windows OCR — системный компонент Windows. Снимки экрана обрабатываются локально, без облачного API.

Black Myth: Wukong Benchmark Tool принадлежит правообладателям игры и не включён в поставку. Пользователь устанавливает его отдельно через Steam.
