# Результаты запуска

Проверка выполнена 5 октября 2026 года. Программа сама запустила оба теста и прочитала результаты с экрана.

Компьютер: Intel Core i5-14600KF (14 ядер, 20 потоков), NVIDIA RTX 5070 (12 GB), 32 GiB RAM. Windows build 22621, драйвер NVIDIA 610.88, Benchmark Tool 1.0.3.14649.

| Параметр | CPU-тест | GPU-тест |
|---|---|---|
| Разрешение | 1280×720, окно | 2560×1440, без рамок |
| Масштаб рендера | 25% | 100% |
| Качество | Низкое | Максимальное |
| Полная трассировка | Выкл. | Ультра |
| Генерация кадров | Выкл. | Выкл. |
| Средний FPS | 211 | 90 |
| Минимальный FPS | 110 | 69 |
| Максимальный FPS | 284 | 110 |
| 5-й перцентиль FPS | 191 | 77 |

В CPU-тесте графика снижена, чтобы видеокарта меньше влияла на результат. Дополнительный тест при 960×540 дал 213 FPS вместо 211. Изменение около 1% поддерживает выбор настроек на этом ПК.

В GPU-тесте графика и трассировка выставлены на максимум. Отдельное наблюдение показало загрузку GPU 99%; средняя загрузка за весь тест не измерялась.
